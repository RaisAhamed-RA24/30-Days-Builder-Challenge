# Smart Expense Intelligence 💰

A personal finance dashboard built using HTML, CSS, JavaScript and Chart.js to track income, manage expenses and understand spending patterns.

## Features

- Add income and expense transactions
- Calculate total income, expenses and balance
- Categorize transactions
- Search and filter transactions
- Delete transactions
- Store data using LocalStorage
- Visualize expenses using charts
- Monthly financial insights
- Six-month spending trend

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser LocalStorage

## Getting Started

1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start adding transactions.

## How It Works

The application uses JavaScript to calculate financial summaries and update charts dynamically.

Transaction records are saved in browser LocalStorage, allowing data to remain available after refreshing the page.
